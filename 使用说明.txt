========================================
 UHFReader18 学生签到签退考勤系统 使用说明
========================================

★ 图形版（新版，推荐）：双击「启动考勤系统.exe」即可

一、项目文件说明
----------------
  启动考勤系统.exe     图形界面主程序（日常就双击这个）
  attendance.db        数据库（人员名单 + 考勤记录，勿删）
  UHFReader18.dll       读写器驱动库（勿删勿改）
  启动考勤系统.bat     命令行旧版入口（一般用不到）
  attendance_system.py  命令行旧版主程序（一般用不到）
  students.txt          旧版名单文件（仅旧版使用）
  考勤记录.csv          旧版导出的考勤结果

二、运行前的准备
----------------
  1. 关闭官方演示软件 UHFReader18demomain.exe，
     否则串口被占用，程序会提示"串口已被占用"。

  2. 读写器通过 USB 线连接电脑（设备管理器 -> 端口 ->
     USB-SERIAL CH340 (COMx)  查看串口号），在「设置」页选择。

三、发卡（新卡必须做这一步！）★重点
------------------------------------
  空白 UHF 卡出厂时卡号(EPC)往往是**完全相同**的，
  于是多张新卡刷出来一模一样 —— 谁刷都显示成同一个已注册的人，
  这就是"新卡一刷就变成别人"的原因。

  解决办法：给每张卡烧一个独一无二的卡号（发卡）。

  操作步骤：
    1) 打开左侧「📝 学生注册」页
    2) 把要发的新卡放到读写器天线上（感应区显示"1 张卡"，
       **必须只有一张卡**，两张以上写卡会失败）
    3) 点「开始读取卡片」，卡号会自动填入上方框
    4) 在「🆔 发卡」区点「✍ 写入卡号」
       （新卡号已自动生成，也可以自己改）
    5) 确认弹窗后，写卡完成，卡号框会变成刚写入的新卡号
    6) 填写学号、姓名，点「保存并注册」→ 完成

  写卡须知：
    * 写卡**不可撤销**，原卡号立即失效
    * 写卡后程序会回读校验，确保新卡号真的生效
    * 有些只读型号的读写器不支持写卡，此时会明确提示

四、日常使用
------------
  第 1 步：启动
     双击「启动考勤系统.exe」，左下角显示"已连接 COMx"即可。

  第 2 步：登记学生
     「📝 学生注册」页 → 刷卡读卡号 → 填学号姓名 → 保存并注册。
     刷到没登记过的卡时，实时考勤页会显示"未注册卡片"，
     并有「✍ 去注册这张卡」按钮，一键跳到注册页并带上卡号。

  第 3 步：刷卡考勤
     学生第一次刷卡 -> 签到（有"嘀"声提示）
     学生第二次刷卡 -> 签退，自动计算上课时长

  第 4 步：查记录
     「📊 考勤记录」页按日期/姓名筛选，可导出 CSV。

五、常见问题
------------
  1. 提示"串口已被占用" -> 关闭官方演示软件后重试
  2. 提示"连接失败"     -> 检查 USB 线；在「设置」页确认串口号
  3. 读不到标签         -> 确认用的是 UHF(900MHz) 电子标签，
                           且贴近天线面板 5～15cm
  4. 一次刷卡被记多次   -> 「设置」页调大"同卡冷却时间"
  5. 新卡一刷就显示别人  -> 空白卡卡号相同所致，请按第三节"发卡"
  6. 刷卡没反应         -> 看「实时考勤」页右下角"感应区 N 张"：
                           0 张 = 读写器没读到卡（位置/功率问题）；
                           N 张 = 多卡串扰，移走多余的卡
  7. 写卡失败           -> 确认感应区只有一张卡；卡片是否支持改写
                           EPC 区；读写器是否支持写卡
